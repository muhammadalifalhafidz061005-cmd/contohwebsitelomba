System Architecture & Mechanics

Technical documentation of the data pipeline and hardware mechanics.

1. Closed-Loop Data Pipeline

  1. Vision: Teachable Machine mendeteksi kelas objek (Yellow/Black/Red) melalui webcam.
  2. Database Entry: Website mengirim record baru ke Firebase /transactions dengan status Pending.
  3. Command TX: Website mengirim string perintah (misal: YELLOW_ROBOTIC) melalui Web Bluetooth UART ke Mikrokontroler.
  4. Execution: Mikrokontroler memproses perintah, menjalankan motor conveyor, dan menggerakkan aktuator lengan/servo ke koordinat yang ditentukan.
  5. Validation: Sensor IR / HC-SR04 di dalam destination bin terpicu saat objek jatuh melewatinya.
  6. Feedback RX: Mikrokontroler mengirim string feedback (misal: IN_YELLOW) via Bluetooth kembali ke website.
  7. QC Update: Website mencocokkan transaksi Pending dan memperbaruinya menjadi Success atau Miss-sort.

2. How the Robot Works (Mekanisme Kerja)

Sistem perangkat keras bertindak sebagai eksekutor fisik yang menerjemahkan sinyal digital menjadi pergerakan mekanis melalui dua mekanisme sorting yang diatur oleh mikrokontroler pusat:

Mode 1: Servo Sorting

Mekanisme ini dirancang untuk high-throughput sorting (pemilahan berkecepatan tinggi). Saat objek berjalan di atas konveyor, motor servo bertindak sebagai sorter gate (gerbang pemilah). Servo akan memutar lengannya secara instan pada sudut tertentu untuk membelokkan material agar meluncur masuk ke bin Kuning atau Hitam secara akurat tanpa menghentikan laju konveyor.

Mode 2: Robotic Recovery

Mekanisme ini dirancang untuk precision handling, khususnya untuk material Reject/Red. Konveyor akan berhenti saat objek mencapai area pengambilan. Lengan robot multi-axis (digerakkan oleh servo high-torque seperti MG996R) akan bergerak menggunakan kalkulasi inverse kinematics dan interpolasi linear untuk memastikan transisi pergerakan yang halus (smooth motion) saat memindahkan objek ke recovery bin.

Integrasi Hardware Utama

  • Microcontroller & UART: Berfungsi sebagai otak logika lokal yang mengontrol motor driver (misal: Cytron/BTS7960) dan menerima instruksi serial dari Web API.
  • Conveyor Drive: Digerakkan oleh motor DC gearbox (seperti JGA25-370) untuk menjaga torsi dan kecepatan lintasan agar klasifikasi AI sinkron dengan waktu tiba material.
  • Sensory Feedback: Array fotodiode atau sensor ultrasonik mengawasi setiap lubang penyimpanan, mendeteksi perubahan fisik instan untuk memicu balasan ke dashboard.
